# ЖК Мелодия

Учебный проект сайта жилого комплекса «Мелодия».
Выполняла : Кисапова Есения Ир3-23
## Что есть на сайте

- шапка сайта с логотипом из SVG;
- выбор этажа стрелками;
- выбор этажа мышкой на доме;
- подсветка выбранного этажа;
- модальное окно с квартирами;
- подсветка квартир при наведении;
- разные квартиры на каждом этаже.

## Стек

- HTML
- CSS
- JavaScript
- SVG
- Figma

## Запуск

Открыть `index.html` через Live Server.
